# Beginning Portfolio

This is my first completed personal portfolio project built using HTML and CSS.

## About the project
I created this project to understand the basics of structuring a web page using semantic HTML and applying simple CSS for layout and styling. This portfolio represents my initial attempt at building a complete  
project independently.

Before this, I had started similar projects but did not finish them. This project is important to me because it is the first portfolio that I completed end-to-end.

## What I learned

- Writing simple and readable CSS
- Organizing content into sections
- Completing a project despite initial confusion

## Technologies used
